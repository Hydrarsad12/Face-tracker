Why This Is Happening You opened index.html directly from your phone's file manager (Files by Google). In Android Chrome, opening files this way assigns them a content:// scheme (an opaque/null origin). By design, Chromium strictly blocks camera access (getUserMedia) on content:// and file:// addresses, even if you have granted Chrome system-level camera permissions in your Android settings. To allow the camera to turn on, the page must be served through a real web address (HTTPS or localhost). In mobile browsers, blendshape scores often peak between 0.25 and 0.35 for natural smiles and facial expressions, leaving the detector stuck on "Neutral". Mobile GPU Delegation: On certain mobile chipsets, WebGL/WebGPU tensor delegation for blendshapes can encounter driver limitations, causing blendshape arrays to return empty or uncalibrated values. Model Download Timing: Model initialization previously started only after the camera opened, meaning facial tracking remained idle during the initial download over mobile data. What Has Been Fixed in This Update Dual-Engine Emotion Analysis (Geometry + Blendshapes): Smile / Happy: Now combines blendshapes with physical 3D geometry—measuring mouth corner elevation relative to the upper lip and the ratio of mouth width to facial width (temple-to-temple). Mouth Open / Surprise: Measures the real-time Mouth Aspect Ratio (MAR) ( Lip Height/Lip Width) in addition to the jaw drop coefficient. Wink / Blink Detection: Computes the Eye Aspect Ratio (EAR) independently for each eye, immediately registering winks and blinks. Eyebrow Elevation & Furrow: Measures the physical distance between eyebrows and eyes to reliably detect raised brows and frowning. Calibrated Sensitivity: Thresholds have been adjusted to reflect natural mobile camera distances and everyday facial expressions. Automatic GPU → CPU Fallback: If mobile GPU acceleration encounters an error, the system automatically falls back to CPU mode to keep tracking active. Immediate Pre-loading: MediaPipe models now start downloading as soon as the webpage loads, so the tracker is ready when you start the camera.
